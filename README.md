# IPL_Analysis_Dashboard

An interactive data analysis dashboard built with Python and Streamlit.

## What it does
- Analyses IPL match data from 2008–2020
- Shows top teams, host cities, players, and season trends
- Filter by season using the sidebar

## Tools used
Python, Pandas, Seaborn, Matplotlib, SQL, Streamlit

## How to run
pip install -r requirements.txt
streamlit run app.py
